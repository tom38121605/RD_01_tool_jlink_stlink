

烧录nrf82833的bootloader文件，跟stm32c011，区别是导入要烧录的bootloader.hex文件后，增加了两个merge的步骤


5.    导入要烧录的hex文件，点击菜单 File -- open file data，导入文件 （如bootloader_c011.exe）

51.  merge "MBR"文件
      菜单 file -- merge data file  --  选中 mbr_nrf52_2.4.1_mbr.hex 文件進行合并

52.  merge "readback protection"文件
      1). 新建一个readback protection文件, 文件名为 readBack.hex （文本文件格式），内容如下三行

:020000041000EA
:0412080000000000E2
:00000001FF 

      2). 菜单 file -- merge data file  --  选中 mbr_nrf52_2.4.1_mbr.hex 文件進行合并



（其他步骤完全相同）
